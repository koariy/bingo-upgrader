# Проверка финальной 1.0.0

Minecraft 26.2 / Oracle JDK 25 / Fabric Loader 0.20.1 / Fabric API 0.161.0+26.2,
Gradle 9.5.1, Loom 1.17.21. Итог: **BUILD SUCCESSFUL**.

## Автоматические проверки

| Модуль | Количество проверок |
| --- | --- |
| Ценности | 23 |
| Апгрейдер | 88 |
| Бинго | 774 |
| UI / animation math / новые packets | 13082 |
| Всего | 13967 |

Это число отдельных assert-проверок в исполняемом harness `valueChecks`,
а не 13967 независимых JUnit-сценариев. В build/check он выполняется автоматически;
задача framework test отключена, поскольку дополнительного framework нет.

Дополнительно 12 млн Bernoulli-прогонов (6 пар × 2 млн) и 100 генераций карточек.
Отчёт баланса: `build/value-checks/balance.csv`; также вложен в release.
Проверены реальные Minecraft data components, NbtOps round-trip для матча и
флагов сдачи/free center, codec requestId/TTL/catalog, геометрия выигрышной
остановки у краёв вероятности, независимость сглаживания от 60/144 FPS,
обратное отображение координат для пяти размеров GUI. Финальная политика
unknown-призов имеет отдельные проверки default deny и явного opt-in.

Проверены 112 совпадающих ключей ru_ru/en_us и структура всех JSON ресурсов.
Полные examples экспортированы тестом из runtime-моделей, включая
`allowUnknownTargets=false`. JAR содержит клиентские классы, ресурсы, mixin
конфиг и подставленную версию 1.0.0.

## Живой клиент / одиночный сервер

Проверка выполнена настоящим `runClient` в созданном для неё локальном мире,
без подключения реального аккаунта. Снимки — `docs/screenshots/`, без макетов.

- Открытие апгрейдера клавишей U; интерфейс, каталоги и русская локализация.
- 64 палки → алмаз: серверное превью 23.04%; реальная попытка с неудачей,
  списание до анимации, корректная конечная зона.
- 144 железных слитка из трёх стопок → алмазный блок: 82.29%; Shift-клики,
  точный поиск цели, ожидание дольше исходного TTL, успешная попытка после
  автоматического обновления превью. Приз появился в инвентаре, клетка бинго
  отметилась в том же серверном ходе.
- Создание solo-матча командой, карточка, таймер, отметка по получению предмета.
- Штатное сохранение/выход и повторная загрузка: прежняя карточка и отметка
  восстановились по прежнему UUID.
- Карточка и настройки бинго, HUD-редактор: перетаскивание, масштаб 1.1,
  запись изменённых координат/масштаба в клиентский JSON.
- Английские и русские надписи; шрифт отображает кириллицу.

Среда использовала Xvfb/software OpenGL. Это проверка поведения и картинки,
не аппаратный FPS benchmark. OpenAL запускался на No Output: aliases ресурсов
загрузились, но субъективная слышимость/громкость не проверялась.
Последнее ограничение unknown-целей и обработка финальной координаты отпускания
HUD добавлены после визуального прохода и покрыты сборкой; политика unknown
дополнительно проверена автоматически.

## Выделенный сервер

Финальная 1.0.0 загружена настоящим Fabric SERVER bootstrap: регистрация main,
блока, mixin и networking прошла, клиентские классы не потребовались. Запуск
остановился штатно на требовании EULA, согласие автоматически не принималось.
Отдельная игровая сессия с несколькими сетевыми клиентами и Vulkan backend
в этой среде не проверялись.
