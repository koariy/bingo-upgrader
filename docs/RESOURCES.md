# Ресурсы темы

Все перечисленные файлы включены в проект и готовы к использованию. Это простая
оригинальная пиксельная тема, а не отсутствующие заглушки. При желании можно
заменить изображения более детальными, сохранив пути и layout атласа.
Корень: `src/main/resources/assets/bingo_upgrader/`.

| Файл | Размер | Назначение |
| --- | --- | --- |
| textures/gui/panel.png | 32×32 RGBA | Девятисегментная панель: скругление, обводка, синий градиент |
| textures/gui/button.png | 32×32 RGBA | Общая кнопка, девять сегментов |
| textures/gui/button_hover.png | 32×32 RGBA | Тёплая подсветка кнопки/ползунка |
| textures/gui/slot.png | 32×32 RGBA | Единая рамка слотов бинго/апгрейдера |
| textures/gui/honeycomb.png | 48×32 RGBA | Бесшовный гексагональный паттерн, без растяжения тайла |
| textures/gui/check.png | 16×16 RGBA | Зелёная галочка клетки |
| textures/gui/pointer.png | 16×20 RGBA | Стрелка колеса, поворот относительно центра |
| textures/gui/wheel_atlas.png | 2432×2432 RGBA | 19×19 кадров 128×128; кадры 0..360 — число градусов выигрышного сектора |
| textures/gui/glow.png | 128×128 RGBA | Радиальная вспышка, окрашивается зелёным/красным в коде |
| textures/block/upgrader.png | 16×16 RGBA | Самостоятельная текстура блока с золотым кольцом |
| icon.png | 128×128 RGBA | Иконка мода |

Nine-slice использует границы 6 px: углы 6×6, центр 20×20. Для совместимой
замены сохранять эту геометрию. У кольца начало наверху, направление по часовой
стрелке; кадр i расположен `(i%19*128, i/19*128)`. Кадры после 360 не используются.
Цвета: фон #111827/#1E293B, золото #FFB547, зелёный #59D990, красный #EF6464.
Частицы рисуются маленькими GUI-прямоугольниками, отдельная particle texture не нужна.

`tools/generate_ui_assets.py` воспроизводит PNG через Python + Pillow. Генератор
не вызывается Gradle и не требуется пользователям. Команда для автора ресурсов:

```sh
python tools/generate_ui_assets.py
```

## Звуки

`sounds.json` определяет законченные aliases к стандартным ресурсам игры:

| Event ID | Источник | Применение |
| --- | --- | --- |
| bingo_upgrader:click | minecraft:ui.button.click | Кнопки, короткий тихий отклик |
| bingo_upgrader:tick | minecraft:block.note_block.hat | Дребезжание стрелки по секторам |
| bingo_upgrader:success | minecraft:entity.experience_orb.pickup | Ding выигрыша и линии бинго |
| bingo_upgrader:failure | minecraft:block.note_block.bass | Низкий звук неудачи |

OGG из Minecraft не копируются в мод. Чтобы добавить собственный sample, положить
например `sounds/ui/tick.ogg` и заменить соответствующий sounds.json entry на
`{"name":"bingo_upgrader:ui/tick","volume":0.25}` (без `type:event`). Для UI
подходят короткие 0.03–0.2 s клики, 0.3–0.8 s ding, mono/stereo Vorbis, 44.1/48 kHz.
Звук не управляет исходом и не требуется для его понимания. Частота щелчков
ограничена client tick — не больше одного звука за кадр tick, независимо от FPS.

## Шрифт и локализация

Используется встроенный `minecraft:default`, пиксельный и с кириллицей.
Отдельные TTF/лицензии/загрузка шрифта не нужны. Собственный шрифт при замене
должен включать ASCII, кириллицу, знаки ×/−/% и оставить читабельность при GUI Scale.
Галочка — текстура, не зависимость от конкретного Unicode-глифа шрифта.
Все UI-надписи в `lang/ru_ru.json` и `lang/en_us.json`; ID предметов, числа и
математические символы динамические. Никакого текста не запечено в PNG.
